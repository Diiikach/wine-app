# Wine Quality — демо на Streamlit

Приложение показывает, как логистическая регрессия из ДЗ-3 отбирает "хорошие" вина, позволяет
покрутить порог решения, посмотреть метрики на тестовой выборке и прогнать свой CSV-файл.

## Запуск

Python 3.15 (можно и 3.10+, фиксированных несовместимостей с более старыми версиями нет, но
версии зависимостей в `requirements.txt` подобраны под 3.15 — если ставите на более старый
Python, допускается собрать окружение с более старыми совместимыми версиями этих же пакетов).

```bash
cd wine_app
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется в браузере на `http://localhost:8501`.

## Файлы

- `app.py` — само приложение (4 вкладки + порог в сайдбаре);
- `model.joblib` — обученный пайплайн (`StandardScaler` + `LogisticRegression`), модель внутри
  приложения не переобучается;
- `config.json` — порог по умолчанию ($t_{F_1}$, подобранный на валидации в ноутбуке);
- `test.csv` — тестовая выборка, на которой считаются метрики во вкладке "Модельные метрики".

## О кэшировании

Модель грузится функцией с `st.cache_resource` — это кэш для **объектов** (один экземпляр на
процесс сервера), а не для данных. `test.csv` и предсказанные вероятности на нём кэшируются через
`st.cache_data`, который кэш по значению/хэшу аргументов — поэтому аргумент-модель в
`test_proba(_model, X)` назван с подчёркивания: Streamlit не пытается хэшировать сам объект
модели (это было бы дорого и не нужно, т.к. модель не меняется между вызовами).

Без `st.cache_resource` модель читалась бы с диска через `joblib.load` заново при каждом
перезапуске скрипта — то есть при каждом движении слайдера порога, хотя сама модель от порога
не зависит.
